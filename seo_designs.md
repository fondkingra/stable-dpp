About This Document
This guide contains the complete, upgraded, developer-ready SEO content for the StableDPP website. It rewrites every headline, body paragraph, call-to-action, trust signal, form field, and meta tag across all nine public pages to a top-tier content standard, with full keyword optimisation baked into every element.
It is written to be handed straight to a developer and an SEO specialist. Every page below is laid out in the order it appears on the live site, with each piece of copy clearly labelled by its component type so it can be placed without guesswork.

How to read this guide
Each section is tagged with its component type so the developer knows exactly what they are looking at:
Component labels — EYEBROW · H1 · H2 · H3 · BODY · CTA · BADGE · FORM · META — identify what each block of copy is.
Teal-bordered boxes contain the exact copy to paste onto the website. Nothing else belongs on the live page.
Grey tables hold structured data for reference — field names, links, button styles, and meta values.
Coloured notes (SEO / DESIGN / DEV) are instructions and rationale for the team. They are never live copy and must not be published.
SEO NOTE  Editorial notes have been deliberately separated from the paste-ready boxes in this version, so there is no risk of an instruction being copied onto the live site by mistake.
